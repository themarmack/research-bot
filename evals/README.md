# evals/

Evaluation suites for this repo's skills, consumed by [`evolve`](https://oss.bitwisemedia.uk/evolve/). See [`../TESTING.md`](../TESTING.md) for the full testing model.

Layout (evolve `single`-plugin): one directory per skill, matching the skill name under `skills/` (a symlink to `.claude/skills/`).

```
evals/<skill-name>/
  triggers.yaml   # Tier 1 — prompts + whether the skill should activate
  evals.yaml      # Tier 2 — behavioral cases with assertions / LLM judge (optional)
  results.json    # committed run results (generated by `evolve run …`; evolve's default format)
```

## Running

Prefer the `make` targets (they carry the token-frugal flags):

```sh
make lint      # Tier 0 — static validation (no agents, no credentials, no key)
make evals     # Tier 1 — trigger suites via the claude CLI (LOCAL ONLY)
make gate      # evolve report --check on committed results (no agents)
make report    # rebuild EVALUATION.md from committed results
```

Tier 0 runs free and offline; Tiers 1–2 drive the `claude` CLI (uses your subscription — **no API key needed**; non-deterministic) and should be run manually or on a schedule, with `results.json` committed — **not** run inside CI. CI gates on committed evidence only.

## Model / gating

`.evolve.yaml` pins **Sonnet 4.6** as the single gated oracle (also the LLM-judge model). Haiku produced false-negative trigger results on some skills, so it's too weak to gate on; use `--model` to go cheaper for local smoke.
