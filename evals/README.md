# evals/

Evaluation suites for this repo's skills, consumed by [`evolve`](https://oss.bitwisemedia.uk/evolve/).

Layout (evolve `single`-plugin): one directory per skill, matching the skill name under `skills/` (a symlink to `.claude/skills/`).

```
evals/<skill-name>/
  triggers.yaml   # Tier 1 — prompts + whether the skill should activate
  evals.yaml      # Tier 2 — behavioral cases with assertions / LLM judge
  results.yaml    # committed run results (generated by `evolve run …`)
```

## Running

```sh
evolve run checks      # Tier 0 — static validation (no agents, no credentials)
evolve run triggers    # Tier 1 — needs a harness CLI + credentials
evolve run evals       # Tier 2 — behavioral, runs real agents (cost + credentials)
evolve report          # rebuild EVALUATION.md from committed results
```

Tier 0 runs free and offline; Tiers 1–2 drive real agent CLIs (tokens, credentials, non-deterministic) and should be run manually or on a schedule, with `results.*` committed — not run inside CI. See the adoption notes in `CLAUDE.md`.
