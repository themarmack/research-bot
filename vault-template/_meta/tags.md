# Controlled Tag Vocabulary

Skills and humans tag notes from this list only. Adding a new tag is a `_meta` change — propose via decision in `decisions/`, then add here.

## Domain

- `#sdlc` — software development lifecycle (broad)
- `#copilot` — GitHub Copilot specifically
- `#github` — GitHub platform (non-Copilot)
- `#codeql` — CodeQL queries, alerts, packs
- `#dependabot` — Dependabot configuration, triage
- `#ghas` — GitHub Advanced Security (umbrella)
- `#ai-coding-tools` — Cursor, Windsurf, Cody, JetBrains AI, Amazon Q, etc.
- `#frontier-model` — Anthropic / OpenAI / Google / Meta / Mistral model releases
- `#supply-chain` — SBOM, SLSA, Sigstore, dependency security
- `#peer-bank` — what other banks publicly publish
- `#vendor` — vendor evaluation / vendor news

## Regulatory & compliance

- `#regulator` — OCC, FRB, FDIC, FFIEC, SEC, FINRA, CFPB, NYDFS, FCA, ECB
- `#compliance-framework` — NIST 800-53/800-218, PCI-DSS, SOX, ISO 27001/42001, CIS
- `#ai-governance` — NIST AI RMF, EU AI Act, executive orders, model risk

## Note kind (orthogonal to domain)

- `#decision` — applied to anything in `decisions/`
- `#fact` — applied to anything in `facts/`
- `#event` — applied to anything in `events/`
- `#insight` — applied to anything in `insights/`
- `#research` — applied to anything in `research/`
- `#digest` — applied to anything in `digests/`
- `#person` — applied to anything in `people/`
- `#project` — applied to anything in `projects/`

## Workflow status

- `#open` — needs follow-up
- `#blocked` — waiting on something external
- `#stale` — content known to be out of date; needs refresh
- `#superseded` — replaced by a newer note (link the replacement)

## Confidence (in addition to frontmatter `confidence` field)

- `#unverified` — confidence 1, awaiting verification
- `#disputed` — verifiers split; see body for vote breakdown

## Sensitivity

- `#external-only` — references publicly available sources only; safe to share
- `#do-not-share` — contains content the user shouldn't repost externally
